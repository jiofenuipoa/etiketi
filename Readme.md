# AI Скенер за съставките в храната

## Описание
AI приложение за разпознаване на хранителни съставки от снимка, показвайки дали са вредни или полезни.

## Функции
- OCR разпознаване
- Камера
- Health Score
- Анализ по заболявания
- По-здравословни алтернативи

## Технологии
- Streamlit
- EasyOCR
- Python
